# WebP Converter

Turn JPG, PNG and other images into small WebP files for websites.
It runs in your browser: no uploads, no sign-up, no limits.

**Use it online:** https://bfreshbenji.github.io/webp-converter/

## How to use it

1. Open the link above (bookmark it).
2. Drag your images onto the page, or click **Choose images**.
3. Move the **Quality** slider. 75–85 works well for most photos.
4. Optional: pick a **Max width** (1920 is a good choice for full-width website images).
5. Click **Download** next to an image, or **Download all (.zip)** to get them all at once.

## Use it without internet

Download `index.html` from this repo and double-click it. It opens in your browser
and converts images the same way.
